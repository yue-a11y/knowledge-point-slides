# 知识点讲解（HTML 版 PPT）

讲清**一个**知识点：听众听完能动手算、能判断、能反推。
这是讲解，不是名词解释、不是综述、不是文献汇报。

## 何时使用

- 用户说「讲清 XX」「XX 是怎么来的」「做个讲解 PPT」「备课讲一个知识点」「组会讲一下 Tafel 斜率怎么算」
- 用户说「先把要用的公式从最基本的公理推一遍」「别直接甩结论」
- 需要「听完能做到某件事」，而不是「知道这个词是什么意思」

不适用：

- 名词解释、文献综述、论文汇报 → 用 `paper-to-cn-slides`
- 要 Word/PDF 推导文档 → 本技能把推导折叠进 HTML；确实要 docx 才另外用 `scripts/md2docx.py`
- 要 `.pptx` 文件 → 本技能只产单文件 HTML（Ctrl+P 导 PDF）

## 输入槽位

缺任何一项**先问，不要开写**：

| 槽位 | 要求 | 缺失时 |
|---|---|---|
| 知识点 | 一句话，具体到可判定（「LSV → Tafel 斜率怎么取」而非「电化学」） | 必须问 |
| 终点能力 | 动词句：能取 / 能算 / 能判 / 能反推 | 必须问，不要替用户定 |
| 听众 | 谁 + 已知 A、B + 不知道 C、D | 默认「同领域研究生，懂概念不会算」并明示 |
| 起点材料 | 形态 + 量纲 + 范围；预备段之后的第一页必须从它开始 | 必须问 |
| 终点量 | 结论 + 单位 | 必须问 |
| 贯穿算例 | 全篇唯一一组数 | 自造一组，页面上标注「示例数据」 |
| **预备段要几条 P** | **= 从终点量到停点的链长**（沿计算链往下走，走到正文最后一次代入这一式的那一步就停）；闸门 1 的「起点」那一行里报个数 | 自己数，别问；数不出来说明终点量还没定 |

硬规则：

- 全篇只用这一组数。任何一页出现这些数，必须完全一致、带单位。
- 没有实测依据的数字写 `[待补：来源]`，**不许补一个看起来合理的值**。
- 全程中文；术语首次出现给英文原词；同一概念全篇一个叫法，中途不换。
- 每页必须有**屏幕上看得见的页码** `N / M`，并且画布要缩放到视口。
- 每张图必须**声明坐标**（`data-x` / `data-y` / `data-xscale` / `data-yscale`），轴标签写「量 + 单位」。
- 公式里**每个符号**都要 `<var data-sym="…">`；正文页要求本页图上能指到同名符号，预备段页不要求（见「公式预备段」）。
- 每条公式**同页**必须有 `<details class="deriv">` 推导块；全篇有一张 `<details class="recalc">` 数值复算表。
- 每页必须声明**页角色** `data-kind`（**axioms** / formula / origin / theory / calc / pitfall）——**没有结论页**。
- 第 1 页是**公理清单页**（`data-kind="axioms"`，不挂 `data-eq`、不挂推导），随后每条 P 一页（`data-kind="formula"`），起点原图页顺延。

## 输出位置

```text
work/<slug>/                      # slug = 英文小写连字符
├── <slug>.html                   # 单文件幻灯片（唯一产物，推导在页面里折叠）
├── shots/deck-print.pdf          # 整份打印件
├── shots/p-0N.png                # 抽查 ≥3 页截图
└── <slug>-交付说明.md            # 勾选结果 + 没做到的事
```

**不产 docx。** 推导与数值复算都以 `<details>` 折叠块住在 HTML 里。

## 三道闸门（强制，不许跳阶段，不许一次回多个阶段）

### 闸门 1：只回 5 行，等确认

```text
起点：（从哪条公理起；预备段要几条 P）
终点：
听众缺：
贯穿算例：
最容易错的一步：
```

不写正文、不写大纲、不解释为什么这么设计。

「起点」那一行必须报出**预备段要几条 P**：从终点量沿计算链往下走，走到「正文最后一次代入这一式」就停，链长就是 P 条数。报不出 → 终点量还没定，回去问。

### 闸门 2：outline + 坐标表 + 公理表 + 公式预备表 + 正文公式表，一次给全，等确认

五张表的**合并**就是为了少一轮等待，别拆开问。

```text
页码 | 页角色 | 这页让听众做什么判断 | 比上一页多/变了哪个视觉元素 | 一句话结论
```

页角色只能填 `axioms` / `formula` / `origin` / `theory` / `calc` / `pitfall`，与 HTML 的 `data-kind` 一一对应。

- 第 1 页 `axioms` 是公理清单；紧接着每条 P 一页（`formula`）；再往后 `origin` 是起点那张图。
- **最后一页停在最后一个算例（`calc`）或错例（`pitfall`）上**，不再另起一页总结。
- `theory`（成立条件 / 失效后果 / 判据）必须排在任何 `calc` 之前；`pitfall` 至多 1 页。
- 页数**不设上下限**：预备段长度 = 链长，正文长度 = 算例走完所需页数。硬约束只有三条（脚本会判）：
  - **S1**：预备段页数 = 1（`axioms`）+ P 条数（+ 各自的续页）；一页一条 P（续页同 `data-eq` + `data-part`），两条 P 不许挤一页。
  - **S2**：正文顺序不变：`origin` → `theory…` → `calc…` → 至多 1 页 `pitfall`；末页是 `calc` 或 `pitfall`，没有结论页。
  - **S3**：`calc` 占**正文页**（不含预备段）至少一半；`check_deck.py` 会打印「公理 X 条 / 预备段 Y 页 / 正文 Z 页 / calc 占比 W%」，低于 50% 直接 error。
- 最后一页之前，每页都是对**同一张图的递进变形**，不是换一张新图。

```text
坐标表：页 | x 量 | x 刻度 | y 量 | y 刻度 | 与上一页相比变了什么（换了就必须写 recast 那句话）
公理表：A 号 | 标签（定义/定律/经验事实） | 式子 | 为什么它是公理而不是推论 | 被哪几条 P 引用
公式预备表：P 号 | 式子 | 输入量（第几页哪个读数） | 输出量 + 单位 | 起点 A 号 | 步数 | 用于第 N 页 | 停点理由（为什么不再往下推） | 失效条件（带数值）
公式表：页 | 式号 | 式子 | LHS | 推导起点（定义 / 物理前提 / 实验事实 / 哪条 P） | RHS 里每个量在本页图的哪里 | 代入哪几个数 | 误差/失效边界 | 分几页
```

- 「停点理由」或「起点 A 号」为空的行视为**没写**，打回。
- 公理表与公式预备表管 `P1…Pn`；公式表管正文式 `1…n`。**两张表不许混号**：正文引用预备式只写「P2」，不写「式 (P2)」。
- 公理表里出现「Tafel 方程」「Nernst 极限电流」这类**有推导来源**的式子 → 它不是公理，必须给推导。

真实图拿不到时写「拿不到」，**不许用近似图顶替，不许 AI 生图当数据曲线**。

### 闸门 3：产出文件 + 自检全绿

先跑脚手架，再填内容：

```bash
python3 scripts/scaffold.py work/<slug>/outline.json work/<slug>/<slug>.html
```

`outline.json` 格式见 `scripts/scaffold.py` 文件头。它会一次性把页码、视口缩放、坐标声明、轴标签、
刻度占位、公理清单页、P 式页、推导块、复算表、翻页脚本全部生成好——这些靠手写必然漏，漏了就要反复返工。

填完后：

```bash
python3 scripts/check_deck.py work/<slug>/<slug>.html
```

**退出码 0 才算交付**。有 error 就改，不要解释为「模型限制」。脚本会额外打印一行结构摘要：
`公理 5 条 / 预备段 4 页 / 正文 9 页 / calc 占比 67%`。

## 讲法顺序（先公理，后理论，再算例）

顺序错了，后面每一页都在打补丁：

1. **公理清单页**（`data-kind="axioms"`）：文首单列一节 `A1…An`，每条带 [定义] / [约定] / [定律] / [经验事实] 之一，并写 `data-used-in="5,7"`。全文只引编号。
2. **公式预备段**：一条链一页（`P1…Pn`），从 A 编号出发、一步一次变换，推到「正文最后一次代入」就停。
3. **起点页**：只放用户给的那张原图，不叠任何后文标记。标题只能是原图上肉眼可见的事实。
4. **条件页**：在第一次取数之前，把「成立条件 / 违反后图会长什么样 / 判据」一次性讲完。
5. **算例页**：从条件页的判据出发，一页一个动作，正例推导到底。
6. **错例页（至多 1 页）**：三段式易错点集中列，不占多页、不带动画。**错误不靠举例说明，靠条件页的理论提前拦掉。**
收尾停在最后一个算例上：`calc` 页的标题已经写着这一步算出的数与它的意义，**不要另起一页做总结/结论**。

**不出结论页、不出例题页、不出自测题、不出「你学到了什么」。**

## 公式预备段（全篇最前面，第 1 页就是它）

一句话目标：**开讲之前，把讲这个知识点要用到的每一条数学公式，从最基本的公理 / 定义出发、
一步一次变换地推导出来——但只推到本文档真正用到的那一式为止。**
起点永远是公理，终点才是「用到的那一步」。

- **位置**：预备段在全篇最前面：第 1 页是公理清单页（`data-kind="axioms"`），第 2 页起是 P 页（`data-kind="formula"`）。起点原图页顺延到第 N+1 页，仍遵守「不许叠任何后文标记、标题只能是图上肉眼可见的事实」。
- **不是目录**：不许把预备段写成目录页 / 导览页 /「本章公式一览」。
- **页角色**：允许集 `axioms` / `formula` / `origin` / `theory` / `calc` / `pitfall`；`axioms` 只有第 1 页且不挂 `data-eq`。
- **两套号永不复用**：预备段 `P1、P2…`（`data-eq="P1"`），正文核心式仍是 `式 1、式 2…`（`data-eq="1"`）。正文引用预备式只准写「P2」，**不许写「式 (P2)」**。
- **一页一条式**（≤1 条公式）；编号从 P1 连号；一页写不下就续页（同 `data-eq`，`data-part="2"`）。
- **每页必须有 `.io` 行**：`<p class="io">吃进：E [mV]（第 4 页读得到）→ 吐出：η [mV]</p>`。式子的 LHS/RHS 全用 `<var data-sym="…">`，带单位行。
- **可以不带图**；带图就守既有坐标系契约。**「式里的量必须在图上指得到」只管正文页，不管预备段页**。
- **禁止动画、禁止高亮带、禁止滑块**；第 1 页连强调色块都不加。

### 深度：终点闭包 + 起点公理

- **终点（停点）**：从本文档的终点量出发沿计算链往下走，走到「正文最后一次代入这一式的那一步」就停。
  停点之后的内容（机理来源、常数取值、更高阶修正）一律不写。
  原「反向闭包」不许再用来删前置式——它只决定最后一条 P 是哪条。
- **起点**：链条第一步必须是公理清单里的 A 编号，或一条被明确标注的定义。
  **不许从「图上读得到的量」或「教科书结论」起步。**
- **核心步骤不要跳过，换算步可以省略**：产生本知识点判据 / 结论的那几步一条都不许跳；
  纯换算步（换底、换单位、移项、一次等价变形）可以压成相邻式子「依据」里的一行，不单独成页、不占 P 号。
  注意：**换算步可省 ≠ 公理可省**，从公理到该式的路径不许断。

### 定义不推导（P 段准入四条）

**定义式、约定式、纯换算式（取对数、换单位、移项）一律不占 P 号**，写进文首 A 节。
A 条目用 `data-used-in="5,7"` 交代它被哪些页用到；未被任何页用到的 A 是冗余 → error。

P 段准入四条，全满足才许立 P 页：

1. 式子归一化（去空格、去单位、≡ 当 =）后**不等于任何一条 A 的式子**；
2. `deriv` 表 **≥3 步**；
3. 至少 **2 步是真实变换**（取对数 / 引入近似 / 相减 / 与 A 对照定系数）——不许出现
   「照抄 A × → 代常数 → 换个单位」这种三步空转；
4. `data-axiom` 指向的 A 存在，且不是这条 P 自己。

预备段**允许只有 1 条 P**。不许为了「看起来完整」把定义包成 P。
判据：删掉这条 P，听众还能读吗？能 → 它不是预备式，降为 A 条目或正文一行。

本仓库的对照样本（`work/lsv-to-tafel-prep`）：A1 = η 定义、A2 = j = I/A（附 log 注记）、
A4 = E_eq 约定、A5 = 直线斜率 k = Δy/Δx；P 只剩一条 `b = Δη/Δlog₁₀ j`。

脚本判据（C7，全 error）：P 的式子归一化后等于某条 A → `P1 是 A1 的重述，定义不推导`；
推导里「依据 A×」且该行与该 A 一字不差 ≥2 行 → 照抄公理；步数 <3 或真实变换 <2 → 空转。

### 公理清单（文首单列一节，编号 A1…An）

```html
<section class="slide" data-page="1" data-kind="axioms" data-goal="b">
  <h1>三条定义、一条约定、一条定律</h1>
  <ol class="axioms">
    <li data-axiom="A1" data-used-in="5,7"><b>[定义]</b> <span class="eq">η ≡ E − E_eq</span><span class="note">过电位</span></li>
    <li data-axiom="A2" data-used-in="6"><b>[定义]</b> <span class="eq">j = I / A</span><span class="note">纵轴取 log₁₀(j/j_ref)，j_ref = 1 mA/cm²；log 的自变量必须无量纲</span></li>
    <li data-axiom="A3" data-used-in="2"><b>[定律]</b> <span class="eq">j = j₀[exp(α_aFη/RT) − exp(−α_cFη/RT)]</span><span class="note">Butler–Volmer</span></li>
    <li data-axiom="A4" data-used-in="5"><b>[约定]</b> <span class="eq">E_eq = 0.00 V</span><span class="note">RHE 刻度、pH 0 基准下的 HER</span></li>
    <li data-axiom="A5" data-used-in="2,7"><b>[定义]</b> <span class="eq">k = Δy / Δx</span><span class="note">直线 y = kx + c 的斜率</span></li>
  </ol>
</section>
```

- 每条必须带标签，只许四种：`[定义]` / `[约定]` / `[定律]` / `[经验事实]`。判据：
  - **约定** = 刻度 / 参考点的选择（例：RHE 刻度下 HER 的 E_eq = 0.00 V）→ 标 `[约定]`，不标 `[经验事实]`
  - **定律** = 有独立实验支撑的唯象关系（例：BV 方程）
  - **定义** = 纯定义或纯数学（例：η ≡ E − E_eq；直线斜率 k = Δy/Δx）
  - **经验事实** = 具体体系的具体测量值（必须带条件：介质、温度、pH）
- 每条 A 必须带 `data-used-in="5,7"`（它被哪些页用到），且那些页真的引用它；未被任何页用到的 A 是冗余 → error。
- **禁止标签**：`[教科书结论]`、`[已知结论]`、`[显然]`、`[由…可知]`。出现即 error。
- **推论不许升格为公理**。判据：这条式子在本文档之外的文献里是否还有推导来源？
  有 → 它不是公理，必须给推导。（例：Tafel 方程有 → 不能进 A 节；BV 是唯象公理 → 可以）
- **目标量不许进公理清单**。A 节只收三类东西：基本量的定义、守恒律 / 唯象定律、明确的实验事实或测量约定。
  「某个要通过本文档求出的量 = 某条直线的斜率 / = 某个待求关系的系数」是判断结果，不许写成 A 条目。
  文首用 `data-goal="b"` 声明终点量；A 节任一 LHS 出现终点量 → error。
- 斜率要写成**纯数学**（不含任何待求量）：`A5 [定义] 直线 y = kx + c 的斜率 k = Δy/Δx`。
  `b` 的首次出现放在推导里，不许在 A 节：

  ```text
  (3.5) η = (2.303RT/α_aF)·log₁₀(j/j₀) 与 A5 的 y = kx + c 对照（y = η, x = log₁₀j, c = 0）
        → k = 2.303RT/(α_aF)，记 b ≡ k                依据 A5 + 代数
  (3.6) k = (η₂−η₁)/(log₁₀j₂ − log₁₀j₁)                依据 A5（直线斜率定义）
  (3.7) b = Δη/Δlog₁₀ j                                  代数
  ```

- A 条目的 RHS 以另一条 A 的 LHS 开头 → error（公理之间不许互推）。
- **`[近似]` 类不许出现在 A 节**——近似写在引用它的那一步的「依据」列，并当场给数值
  （「η = 150 mV 时还原项占 2.9×10⁻³」），不许写「η 较大时」。

### 口径示例（LSV → Tafel 斜率）

```text
公理清单（文首单列一节，全文只引编号）
  A1 [定义]  η ≡ E − E_eq
  A2 [定义]  j = I / A
  A3 [定律]  j = j₀[exp(α_aFη/RT) − exp(−α_cFη/RT)]        Butler–Volmer
  A4 [近似]  η ≫ RT/F 时还原项/氧化项 < 1%，可略（当场给数值）
  A5 [定义]  b ≡ 直线 η–log₁₀j 的斜率
  —— Tafel 方程不是公理，是 A3+A4 的推论；把它写进 A 节即 error。

P1  η = E − E_eq
  (1.1) η ≡ E − E_eq                                     依据 A1
  (1.2) E 取 vs RHE、HER 的 E_eq = 0.00 V                 依据 A1 + 实验条件
  (1.3) η [mV] = E [mV]                                  代数
P2  log₁₀(j / j_ref)，j_ref = 1 mA/cm²
  (2.1) j = I/A                                          依据 A2
  (2.2) 取对数必须无量纲，故写 log₁₀(j/j_ref)             依据 量纲
  (2.3) 100→2、10→1、1→0                                 代数
P3  b = Δη/Δlog₁₀j = (η₂−η₁)/(log₁₀j₂−log₁₀j₁)
  (3.1) j = j₀[exp(α_aFη/RT) − exp(−α_cFη/RT)]           依据 A3（起点）
  (3.2) j ≈ j₀exp(α_aFη/RT)                              依据 A4；η=150 mV 时还原项占 2.9×10⁻³
  (3.3) η = (RT/α_aF)ln(j/j₀)                            代数：两边取自然对数
  (3.4) η = (2.303RT/α_aF)log₁₀(j/j₀)                    代数：ln x = 2.303 log₁₀x
  (3.5) b = 2.303RT/(α_aF)                               依据 A5 + 系数对比
  (3.6) η₂−η₁ = b(log₁₀j₂−log₁₀j₁)                       代数：在 (3.4) 上取两点差
  (3.7) b = Δη/Δlog₁₀j                                   代数：除以 Δlog
  (3.8) (250−150) mV ÷ 1.667 dec = 60.0 mV/dec            数值：代本 deck 的数
  (3.9) 窗口内不线性时得弦斜率 b_app，偏离真 b             误差与失效边界
  到此为止：不推 α 的物理来源，不推 j₀。
```

示例按原文照录，落成 deck 时有两处必须改：

1. **A4 是 `[近似]`**——按上面「`[近似]` 不许进 A 节」的规则，它要挪到 (3.2) 的「依据」列并当场给数值；
   A 节里换成这个算例真正需要的 `[经验事实]`（例：`A4 [经验事实] 0.1 M KOH、pH 0 基准下 HER 的 E_eq = 0.00 V vs RHE`）。
2. **(3.8) 的 250/150/1.667/60.0 是另一组数**——换成你自己那组贯穿算例
   （`work/lsv-to-tafel-prep` 用 `120 mV ÷ 0.905 dec = 132.6 mV/dec`）。

另外每条 P 还要补两行才能过闸门：用贯穿算例代入的那一行、带数值阈值的失效行（见下面五问第 3、4 问）。
示例里 P1（η 定义）、P2（log₁₀(j/j_ref)）按「定义不推导」应降为 A 条目——它们不产生任何可算的中间量，
删掉后听众照样能读（对照样本 `work/lsv-to-tafel-prep` 就是这么做的）。

### 「讲清楚」的五问——每条 P 式必须五问全答，缺一条算没讲清

1. 这一式把哪个量换成哪个量？（输入量 + 从哪读；输出量 + 单位）→ `.io` 行
2. 它在本文档第几页被用？（`data-used-in="N"`，N 必须是存在的 `calc` 页，且该页真的引用它）
3. 一个数代进去能算出结果吗？（用贯穿算例的数代入，落在该式推导块里）
4. 什么时候不能用？（失效 / 近似条件，一句话，带数值阈值）
5. 这条链的起点是哪条 A 编号？（`data-axiom="A3"`；答不出不许进预备段）

额外：这条链上每一步都不许跳。判定：读者只看 A 节 + 这条链，能否独立复现整条式子？
不能复现 → 中间少了步，补。

### 推导块格式（沿用 `details.deriv`，新增两条列要求）

```html
<details class="deriv" data-eq="P3">
  <summary>推导：BV → b = Δη/Δlog₁₀j（P3）</summary>
  <table><tr><th>步骤</th><th>式子</th><th>依据</th></tr>
    <tr><td>(3.1)</td><td>j = j₀[exp(α_aFη/RT) − exp(−α_cFη/RT)]</td><td>A3</td></tr>
    …
  </table>
</details>
```

- 第一步的「依据」单元格**只能是「A编号」或「定义」**，不许写「已知」「题设」。
- 之后每步的依据只能取：`A编号` / `代数` / `量纲` / `近似及条件`。
- 每步只做一次变换；一页写不下就续页（同 `data-eq`，`data-part="2"`），不许把两步并一行。
- 末尾必须有：**数值代入一行（带单位） + 误差/失效边界一行**。

### 三条既有禁令在预备段怎么用

- **不许解释符号含义**照旧生效：不许「其中 j 为电流密度」「分别表示」。含义靠 `<var data-sym>` + 单位行 + `.io` 行的「进/出」表达。
- **不许用「由式 (N) 得」代替推理**：预备段内部完全生效（P 之间不许互相当代替推导）。
  **正文算例段允许写「依据：P3（已在预备段完整推导）」**——理由：预备段存在的目的就是让后面能引用，而不是重推。
- **每页 ≤1 条公式**不变。

## 页面规范

### 页面不许有元话语（C6，脚本 error）

**元话语 = 关于「本文档怎么组织 / 为什么不那样做 / 后面会讲什么 / 讲解者做了什么」的句子。**
它不是知识点，不许出现在任何幻灯片页面上（标题、lead、正文、图注、列表都不许）。

典型形态：

- 「开讲前先钉死五条」「A1–A5 之外不再假设任何东西」
- 「Tafel 方程不在这五条里：它是 A3 加近似推出来的」
- 「为了讲清楚，我们先…」「本节只讲…」「注意：后面会用到」
- 「这几条是全部前提」「本文档不引入其他假设」

判据一句话：把这句话念给听众，他获得的是「知识」还是「讲解者的说明」？后者删。

去处：只能进 `<slug>-交付说明.md`，或页面里**默认折叠**的 `<div class="notes">`（仅供讲者，
Ctrl+P 打印时必须不展开）。不许留在标题或 lead。

首页（公理清单页）的正确写法：标题只陈述这页有什么（例：「三条定义、一条约定、一条定律」），
下面直接是 `<ol class="axioms">`，不写任何 lead 段落，不解释为什么只列这些。

脚本黑名单：`开讲前 / 本文档 / 不再假设 / 为了讲清楚 / 本节只 / 后面会 / 接下来我们 /
不在这几条里 / 先钉死 / 请记住 / 需要说明的是`——命中即 error，报错带页号与原句。

- 一页一个动作。标题就是这页的结论，不是话题名（写「η 增大时斜率由 60 降到 40 mV/dec」而不是「Tafel 斜率讨论」）。
- **标题与图必须同页同源**：跨坐标系的结论（「变平」「偏离直线」「线性区」）只能出现在纵轴取对数的那一页；线性原图页只说「j 增长变慢」。
- 正文 ≤60 字/页，图为主；只出现当前这一步需要的公式。
- 每页右下角显示 `N / M` 页码，且**画布缩放到视口**（1600×900 固定版式 + `transform: scale` + resize 监听），保证任何窗口下页码都在屏幕内。
- 阶梯必须完整：每步写清「输入 → 操作 → 输出 → 判据」，不跳中间步骤。
- ≥3 条具名易错点，每条三段式：**错误做法 / 现象 / 正确做法**。写成「注意 XX」的视为没写；全部集中在 1 页（`data-kind="pitfall"`）。

## 公式怎么排（手写体 + 真下标 + 展开态）

公式不是正文的一部分，它要看起来像**写在纸上的一行式子**。

- **手写体必须内嵌**。`scaffold.CSS` 自带 `@font-face` 与 `var(--hand)`，字形来自
  `scripts/make_handfont.py` 生成的 `scripts/assets/handfont.css`（LXGW WenKai 子集，
  woff2 约 29KB，base64 后 38KB）。换机器、断网都不掉档。
  子集丢了先跑一次 `python3 scripts/make_handfont.py`；没装源字体时它会 warn，
  此时 `@font-face` 退化成 `local()`，`check_deck.py` 直接 error。
- **只有式子加手绘笔迹**：`<span class="expr">` 下方那条微弯的线，不许把推导块和单位行也圈进去。
- **手写体只挂纯数学元素**：`.formula .expr` 与 `ol.axioms .eq`。子集字体只有 221 个字形
  （ASCII + 希腊字母 + 数学符号 + 上下标），**没有 CJK**；挂到会含中文的元素（`.formula`、推导表的
  式子/依据列、正文）上，中文就会回退到本机系统字体——同一份 deck 在两台机器上字形不一致。
  推导表的式子列因此用正文字体。
- **子集字体的内部名必须是 `DeckHand`**。`make_handfont.py` 会把 name 表改成 DeckHand；
  不改的话 Chromium 的 `CSS.getPlatformFontsForNode` 与 `pdffonts` 会把内嵌子集和系统 LXGW WenKai
  混成同一个名字，「到底回退没有」无法判定（实测踩过）。
- **字形覆盖要查 cmap**：公式元素里的每个字符都必须在内嵌子集里，缺一个就是换机器掉字。
  `check_deck.py` 会解 base64 读 cmap 逐个字符核对。
- **下标用 `<sub>`，不许写 `E_eq`**。`scaffold.subs()` 会把 `X_y` 换成 `X<sub>y</sub>`，
  `sub/sup` 已压掉行高（`line-height: 0`），不会把 48px 的行撑成 60px。
  `data-sym` 属性保持 `E_eq` 原样——绑定检查靠它，符号归一由 `sym_key()` 处理。
- 变量斜体、单位正体。**倾斜只给式子本身**（`.formula .expr`，−0.3°）；`.formula` 块、单位行、
  推导表、图注、正文一律水平。把 rotate 挂在块级元素上，里面的表格会跟着转：
  1428px 宽的表在 0.3° 下两端高差 7.5px，肉眼可辨，导出的 PDF 同样斜。
- 量倾斜与字形来源：`python3 tools/measure_deck.py <html> --tilt` / `--fonts`
  （验收线：表格 |Δy| ≤ 1px、公式元素只用 DeckHand）。

**折叠块必须「展开后仍在一页内」。** 屏幕态是折叠的，一展开就顶出 900px，
`overflow: hidden` 会把下半截直接裁掉——观众看到的是半张表。规则：

- 一条 `details` 展开后，页面 `scrollHeight` 不得大于 900px；
- 复算表**单独成页**（同页有图且行数 > 8 = 必然溢出，脚本直接 error）；
  写不下就拆 `data-part="1"` / `"2"`；单独成页时必须 `<details class="recalc" open>`——
  默认折叠的末页等于一张空白页，讲的时候还得先点一下；
- 判定靠真浏览器：`python3 tools/shoot_deck.py <html>` 会把本页所有 `details` 打开再量一次
  `scrollHeight - clientHeight`，> 1px 就报 `✗ … 展开 N 个折叠块后溢出 Xpx`。
  它同时核对打印页数 == 幻灯片页数（多一页就是内容溢到下一页）。

## 坐标系契约（换坐标 = 换一整套）

只要坐标变了（E → η、j → log j、刻度重排），下面五样必须**同时**改，缺一样就算错页：

1. 轴标签（`<text class="ax" data-axis="x|y">量 [单位]</text>`）
2. 刻度值与刻度形态（`data-axis` 标在每个刻度上；对数轴写 `10⁻²`，不许出现 0）
3. 图注里的量名
4. 正文里提到该量时的名字
5. 一行 `<p class="recast">旧量 → 新量 = 换算关系（刻度是否变）</p>`

额外规则：

- 纵轴取对数就直接写 `log₁₀ j [mA/cm²]`；**禁止**「j [mA/cm²]（对数）」这种把刻度塞进单位括号的写法。
- 几何标注必须带方向：`data-span="x"` 的边只能量横轴的量，`data-span="y"` 只能量纵轴的量。Δ 量画错方向是最常见的翻车点。
- 一张图只声明一组坐标；换图不要偷偷改声明。

## 动画白名单（只做这四类）

1. 坐标轴变换（线性 ↔ 对数、刻度重排）
2. 数据点沿曲线移动，标出当前取的区间
3. 拟合线扫过区间、几何量的边长标注出现
4. 参数滑块驱动图形与公式数值同步

配额与判据：

- 全篇动画页 **≤3**，同一种动画**只用一次**。
- 每个动画必须绑住公式里的一个量：删掉后听众会失去哪个数？说不出来就删。
- **错例页禁止动画**：错误用静态对比 + 三段式文字。
- 第 1 页禁止任何叠加标记（高亮带、拟合线、标注、动画）。

判据：**删掉这个动画观众仍能理解 → 不做。**

禁止：入场动画、呼吸浮动、粒子背景、打字机、转场特效、无关 hover、emoji 当图标。

## 公式、推导与数值复算（全部住进 HTML）

幻灯片页面上只留**正文核心式**：

- **不再设「全篇核心式 ≤3 条」**：核心步骤（产生本知识点判据 / 结论的那几步）一条都不许跳过；
  纯换算步（换底、换单位、移项、一次等价变形）可以压成相邻式子「依据」里的一行，不单独成页。
  需要卡上限时手动给 `--max-eq N`，默认不卡。
- 一个关系全篇只出现一次；**不许移项/代入后另编一个式号**。正文可以写「同式 (2)」指代，但推导里不许拿「由式 (2) 得」当依据（见下节）。
- 同一个量的左边（LHS）不许在两条式子里各当一次主角。
- 每页最多 1 条公式，带编号（式 1、式 2…，全篇连续）；预备段用另一套号 `P1、P2…`，两套永不复用。
- 每个符号写成 `<var data-sym="j">j</var>`，且正文页**至少一个符号必须在本页图上找得到**（预备段页不要求）。
- 页面上出现「补偿 / 外推 / 换算 / 折算 / 归一化 / 校正」这类操作词时，该页**必须给出该操作的定义式**（例如 `E_meas = η_kin + R_u·j`）。
- 页面正文里**不铺推导**，也不许出现「两边取对数」「代入整理得」「移项得」这类推导链。

推导写在公式旁边的折叠块里（原 docx 的内容搬到这里）：

```html
<details class="deriv" data-eq="1">
  <summary>推导：Butler–Volmer → Tafel（式 1）</summary>
  <table>
    <tr><th>步骤</th><th>式子</th><th>依据</th></tr>
    <tr><td>(1.1)</td><td>j = j₀[exp(α_aFη/RT) − exp(−(1−α_a)Fη/RT)]</td><td>定义：BV 方程（起点，不引用别式编号）</td></tr>
    <tr><td>(1.2)</td><td>j ≈ j₀ exp(α_aFη/RT)</td><td>近似 A1：η = 150 mV 时还原项/氧化项 = 2.9×10⁻³，故可舍</td></tr>
    <tr><td>(1.3)</td><td>η = (RT/α_aF)·ln(j/j₀) = b·log₁₀(j/j₀)，b = 2.303RT/(α_aF)</td><td>代数：取自然对数再换底；量纲：mV / dec</td></tr>
    <tr><td>(1.4)</td><td>log₁₀(j/j₀) = 150 mV ÷ 60 mV/dec = 2.5 dec</td><td>代数：代入本页的数（η = 150 mV、b = 60 mV/dec）</td></tr>
    <tr><td>(1.5)</td><td>η &lt; 60 mV 时还原项不可忽略，误差可达 10%</td><td>误差与边界：低过电位段不能用式 (1)，假设 A1 失效</td></tr>
  </table>
</details>
```

**推导只讲一件事：这个式子是怎么被推出来的。** 具体是四条：

1. **从起点写起**：第一步必须是定义、物理前提或实验事实（BV 方程、Tafel 形式、欧姆降的定义、测量得到的两个读数…），不许从另一条式子的编号起步。
2. **一次一步，代数链条不断**：每行只做一次变换（取对数 / 相减 / 取极限 / 代入常数），并在「依据」列写清为什么这一步合法（定义 / 物理前提 / 假设 A1 / 代数 / 量纲）。
3. **落到本页的数**：必须有一行把这一页的数字代进去，算出这一页的结论（`(250−150) mV ÷ 1.667 dec = 60.0 mV/dec`），数字与 `recalc` 表一致。
4. **误差与失效边界**：这个式子什么条件下不成立、偏差多大（`端点读数 ±2 mV → b 偏差 ±1.2 mV/dec；窗口弯曲时得到的是弦斜率`）。

**两条硬禁令**：

- **不许解释符号含义**。「其中 j 为电流密度」「η 表示过电位」「j₀、b 分别是…」一律不要——符号与单位写在公式的 `<var data-sym>` 与单位行里，推导只写怎么算。
- **不许用「由式 (N) 得」代替推理**。前一条式子只是结论；读者要的是这一步的前因后果。数学上必须能独立走通：把第 N 式的内容直接写出来，再往下推。

**唯一例外（预备段的用处）**：正文算例段允许写「依据：P3（已在预备段完整推导）」。理由：预备段存在的目的就是让后面能引用，而不是重推。但预备段**内部**不许 P 之间互相引用。

**一页写不下就多写几页**。推导默认住在公式旁边的折叠块里；装不下时拆片：

```html
<!-- 第 5 页：公式与第 1 片 -->
<details class="deriv" data-eq="2">…</details>

<!-- 第 6 页：同一条式子的第 2 片（页面 data-kind="calc"） -->
<details class="deriv" data-eq="2" data-part="2">
  <summary>推导（第 2 段）：式 (2)</summary>
  <table><tr><th>步骤</th><th>式子</th><th>依据</th></tr>…</table>
</details>
```

分片规则：第 1 片必须与公式同页；续片落在**后面的 `calc` 页**；分片号从 1 连续；总步数按所有分片合计，≥3 步；误差/失效边界可以放在最后一片。

硬要求（脚本校验）：

- 每条公式至少要有一个 `data-eq` 与之相同的推导块第 1 片，且与公式同页。
- 合计 ≥3 步；必须有「依据」列，且每行落到 定义 / 物理前提 / 实验事实 / 哪条 P / 代数 / 量纲 / 误差，不能是空泛的「整理得」。
- 必须有一行数值代入（带单位的结果）；必须有一行写误差、偏差、适用范围或失效条件；必须引用公理编号 A1、A2…。
- 全篇禁止出现「由式」「由上可知」「显然」「易得」「已知结论」「其中」「分别表示」「符号说明」这类字样（脚本 error）。
- 首末两条式子的推导里各查一次量纲；同一个参数全篇只取一个值。

数值复算表（原 docx 的另一半内容，放在任一 `calc` 页）：

```html
<details class="recalc">
  <summary>数值复算</summary>
  <table>
    <tr><th>输入</th><th>计算</th><th>结果</th><th>对应</th></tr>
    <tr><td>j 0.50 → 23.2 mA/cm²</td><td>log₁₀(23.2/0.50)</td><td>1.667 dec</td><td>第 5 页 Δlog j</td></tr>
    <tr><td>100 ÷ 1.667</td><td>除法</td><td>60.0 mV/dec</td><td>式 (2)</td></tr>
  </table>
</details>
```

要求：≥3 行；幻灯片上每个带单位的数字都要能在这里找到出处。

## 图与数据（数据驱动，不要逐点内联）

- 示意图手写内联 SVG，但**曲线必须「数据数组 + 一个渲染函数」**：点存成
  `<script type="application/json" class="deck-data">` 或一个 `const D=[[x,y],…]`，由 JS 生成 `points`。
  单条 `points` 串 >2400 字符或整份 HTML >320KB 会被提示改写。
- 每张图声明 `data-x` / `data-y` / `data-xscale` / `data-yscale`；轴标签用 `<text class="ax">`，刻度用 `data-axis` 标归属。
- 引用真实文献图必须标注出处（作者/期刊 + 图号）。
- AI 生成图不得充当数据曲线。
- 拿不到的材料就写「拿不到」。

## 交付形态

- **单文件 HTML，无外网依赖**：字体、脚本、公式全部内联；不用 CDN 的 MathJax / Chart.js。
- 1600×900 固定版式 + `transform: scale(var(--k))` + `resize` 监听 → 任何窗口都完整可见，页码不跑出屏幕。
- 键盘 ←/→ 与滚轮翻页；1 页 1 屏，任何页面不出现滚动条。
- 正文 ≥20px（1600×900 下）；页码 ≥18px；层级 ≤3 级。
- Ctrl+P 导出 PDF 时每页一张、每页一张页面正好一屏；`details` 在打印时自动展开，
  **展开后仍不得超过一屏**（导出前用 `tools/shoot_deck.py` 验一遍；chromium 版 `deck-browser.pdf`
  用 `pdfinfo` 核页数，weasyprint 版用 `pdftotext -f N -l N` 核最后一页内容没被裁）。
- 截图只交「整份 PDF + ≥3 张抽查」，不再逐页 PNG。

完整契约见 `references/deck-contract.md`，常见翻车点见 `references/anti-patterns.md`。

## 为什么上次跑很久（以及怎么不重演）

慢的不是知识点本身，而是**契约返工**与**大文件反复重写**：

| 慢在哪 | 怎么省 |
|---|---|
| 手写契约属性，漏一个就报错，报错就整页重写 | 先跑 `scripts/scaffold.py`，契约一次生成 |
| 每页几百个坐标点写进 SVG，单文件 150KB+，改一次重写一次 | 曲线存数据数组，用渲染函数生成；改数只改数组 |
| 闸门 2、3 各等一轮 | 合并：outline + 坐标表 + 公理表 + 公式预备表 + 正文公式表一次给全 |
| 逐页截图（10 页渲染两遍） | 只出整份 PDF + 3 张抽查 |
| 每改一页就跑一次校验 | 只在「一页画完」和「交付前」各跑一次 |
| docx 转换 + 来回校对 | 已取消：推导折叠进 HTML |

## 禁止

- 定义 → 公式 → 意义 → 应用 → 小结 四段式
- 每页「标题 + 3 个 bullet」
- 「谢谢观看」「欢迎提问」页
- 例题页、自测题、「你学到了什么」
- 单独产 docx（推导已折叠进 HTML）
- 装饰性大图与渐变 hero
- 跳步直接给公式；页面正文里铺推导
- 编造数值
- 只给源码不给截图
- 换坐标只改曲线不改标签（或只改标签不改刻度、图注、正文）
- 把移项后的同一关系再编一个式号
- 一页一个错例（错例只占 1 页）
- 线性图上说「变平 / 偏离直线」
- 起点页就下结论（那是后面几页才证出来的事）
- 页码只写进 HTML 而没做视口缩放（小窗口下直接出屏）
- 推导只写「定义 / 代数」两行就收尾（这是最常见的「公式没讲清」）
- 推导里解释符号（「其中 j 为电流密度」）
- 用「由式 (N) 得」代替推理
- 另起一页写结论 / 小结 / 总结
- 公式排在系统字体里（没有 `var(--hand)`），或用 `E_eq` 这种编程写法当页面对下标
- 复算表/长推导与图挤在同一页，展开后被 `overflow:hidden` 裁掉下半截
- 把上千个坐标点逐点写进 `points`
- 把推论写进公理清单（Tafel 方程、Nernst 极限电流这类有推导来源的式子必须先证明）
- 从「图上读得到的量」或「教科书结论」起步推导
- 用「由式」「由上可知」「显然」「易得」跳步
- 把近似写进公理清单（「η 较大时可略还原项」）；公理未被任何 P 引用
- 把预备段写成目录页 /「本章公式一览」
- 预备段里解释符号；预备段放动画、高亮带、滑块
- 为凑页数给换算步立页（换算步可以压进「依据」列）
- 用「式 (P2)」混写两套号（正文引用预备式只写「P2」）
- 为让新 deck 过而删掉既有 error 规则、或把新校验降级成 warn
- 幻灯片页面上写元话语（「开讲前先钉死五条」「本文档不引入其他假设」「为了讲清楚…」）
- 把定义 / 约定 / 纯换算式包成 P 页（定义不推导；删掉它听众照样能读）
- 把终点量写进公理清单（`b ≡ 直线斜率` 是判断结果，不是公理）
- A 条目之间互推（A 的 RHS 以另一条 A 的 LHS 开头）
- 删页后不重排 `data-used-in` / `data-uses` / 页码 `N / M`
