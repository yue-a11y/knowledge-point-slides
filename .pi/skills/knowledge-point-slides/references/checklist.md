# 验收细则（A–S）

交付时在 `work/<slug>/<slug>-交付说明.md` 里逐条打勾，并写「没做到的事」。
A–S 里凡是标「脚本」的，`check_deck.py` 会自己拦；标「人」的必须人工逐页看。

## A. 递进可解释

抽任意一页（不要挑首页），能说出它比上一页**多了哪个视觉元素**或**变了哪个参数**。
说不出 → 这一页是凑数的，删掉或合并。

## B. 贯穿算例可复算

用第 1 页的数据，按幻灯片给的阶梯一路算到最后一页，数值与最后一页一致。
中途换过数、跳了单位 → 失败。

## C. 易错点三段式

每条必须是：

```text
错误做法：把 j 直接对 E 作图求斜率
现象：斜率随 η 增大而漂移，同一组数据取不同区间得 60 或 120 mV/dec
正确做法：先算 η，再对 log j 作图，只取线性段
```

写成「注意 Tafel 斜率」「需要注意区间选择」的，视为没写。
**全部集中在 `data-kind="pitfall"` 的那一页**：错例不占多页，也不带动画。

## D. 推导块（脚本 + 人）

每条公式必须有一个 `details.deriv[data-eq=N]`，讲清四件事（缺一件就是「没讲清」）：

1. **从起点写起**：第一步是定义 / 物理前提 / 实验事实，不是另一条式子的编号
2. **一次一步的代数链条**：每行只做一次变换（取对数 / 相减 / 取极限 / 代入常数），并在依据列写清为什么合法
3. **落到本页的数**：有一行把数字代进去，算出本页结论（带单位）
4. **误差与失效边界**：什么条件下不成立、偏差多大

两条禁令（脚本报 error）：

- **不解释符号**：「其中 j 为电流密度」「… 分别表示 …」「符号说明」一律不许出现在推导里
- **不用「由式 (N) 得」**：把第 N 式的内容直接写出来再往下推

一页写不下就续页：`<details class="deriv" data-eq="2" data-part="2">`，第 1 片与公式同页，续片落在后面的 `calc` 页，分片号从 1 连续。

另外：合计≥3 步；有「依据」列且每行落到具体来源；引用公理编号 A1、A2…；首末两式各查一次量纲。
正文算例段可以写「依据：P3（已在预备段完整推导）」——这是预备段的用处；但预备段**内部**不许 P 之间互相引用。

**没有结论页、没有例题页、没有自测题、没有「你学到了什么」。** 最后一页停在最后一个算例（`calc`）或错例（`pitfall`）上。

## E. 断网可用

断网打开 HTML：

- 公式正常渲染（没有空白方块）
- 图全部出现（没有裂图）
- 动画能播

任一失败 → 说明用了 CDN 或外链，改内联。

## F. 呈现核对（含页码可见）

交付整份 `shots/deck-print.pdf`，再抽查 ≥3 页（首页、换坐标页、末页）截图。逐页看：

- **页码在屏幕内可见**：把浏览器窗口缩到 1280×720 试一次——这最容易被漏（固定 1600×900 画布没缩放时，右下角页码直接出屏）
- 无内容溢出、无滚动条
- 正文 ≥20px（1600×900），页码 ≥18px
- 无元素遮挡
- 图上每个标注都能指到它的量（不是装饰）

截图放 `shots/p-0N.png`，整份 PDF 放 `shots/deck-print.pdf`。

## G. 交付说明

必须包含：

1. 每页缩略截图（或 `shots/` 路径 + 页数）
2. A–S 勾选结果（含 M2 / N / O / P / Q / R / S）
3. **「没做到的事」清单**（没有就写「无」，但不许省略这一节）

「文件写完」不算交付。缺 G 视为整单未完成。

## H. 公式页扫描

逐页扫：

- 每页公式 ≤1 条，带编号：正文 `1…n` 连续、预备段 `P1…Pn` 连续；两套号不混用、不设条数上限
- 没有「两边取对数 / 代入整理得 / 移项得」
- 每个符号当页有含义与单位
- 公式当页写了适用条件
- **正文页**式里出现的量，本页图上能指到（至少一个，其余在符号表里给单位）；预备段页不要求

## I. 推导与数值复算（脚本 + 人）

推导已折叠进 HTML（`details.deriv`），完整版翻这些块核对：

- 每条公式同页有推导块，式号一致，式子与页面上那条一字不差
- 每步只做一次变换，依据列写清 定义 / 近似 / 代数 / 量纲
- 公理清单 A1、A2… 在第 1 页，推导里逐处引用；P 的首步依据是 A 编号或「定义」
- **单参数贯穿**：同一个参数全篇一个值；近似式里用的值与反算出来的值一致
- 每条近似写了「代入值 → 计算值 → 与正文哪个数对照」
- 首末两式各查一次量纲
- `details.recalc` 表 ≥3 行，覆盖幻灯片上所有带单位的数字

**缺推导块或缺复算表视为整单未交付。**

## J. 坐标系一致（脚本 + 人）

逐页核对，任何一项不一致就算错页：

| 检查 | 例子（错 → 对） |
|---|---|
| 轴标签与 `data-x` / `data-y` 同量 | 横轴已是 η，标签还写 `E vs RHE [V]` → `η [mV]` |
| 刻度形态跟着刻度类型 | log 轴上 `0,10,20` → `10⁻²,10⁻¹,1` |
| 对数轴写法 | `j [mA/cm²]（对数）` → `log₁₀ j [mA/cm²]` |
| 图注量名 | `E 0–0.4 V vs RHE` → `η 0–400 mV` |
| 正文量名 | 轴换了，正文还在说 E |
| recast 一行 | 换坐标的页必须有一行「旧 → 新 = 关系（刻度是否变）」 |
| Δ 标注方向 | Δη 必须横、Δlog j 必须竖（`data-span`） |

## K. 公式最小集（脚本 + 人）

- **不设条数上限**：核心步骤（产生判据 / 结论的那几步）一条都不许跳；纯换算步可以压进相邻式子的「依据」列
- 一个关系只出现一次；每个符号写成 `<var data-sym="…">`
- 不许移项/代入后另编一个式号（正文 LHS 重复即错）；正文可写「同式 (2)」指代，但推导里不许写「由式 (2) 得」
- 每条式说明「为什么必须在这一页出现」，说不出 → 删
- 讲「补偿 / 外推 / 换算 / 折算 / 归一化 / 校正」的页，必须有该操作的定义式
- 预备段用 `P1…Pn`，正文用 `1…n`，两套号永不复用

## L. 页码、视口与结构（脚本）

- **页数不设上下限**：预备段长度 = 链长，正文长度 = 算例走完所需页数
- 每页可见页码 `<span class="pg">N / M</span>`，与 `data-page`、总页数一致
- **画布缩放到视口**（`transform: scale(var(--k))` + resize 监听），否则页码会出屏
- 每页有 `data-kind`，取值只能是 formula / origin / theory / calc / pitfall（没有 summary）
- S1：预备段从第 1 页起连续；一页一条 P（续页同 `data-eq` + `data-part`），两条 P 不许挤一页
- S2：`origin` 只有一页且紧跟预备段；最后一页是 calc 或 pitfall，标题不许写「结论 / 小结 / 总结」
- S3：`theory`（成立条件）必须排在第一个 `calc` 之前；`calc` ≥ **正文页**的一半（脚本会打印占比）
- `pitfall` ≤1 页；推导页里不许出现「错误做法」
- 动画页 ≤3、同种动画只用一次、错例页无动画；预备段全段无动画

## M. 数值可追溯（脚本 + 人）

- 幻灯片上每个带单位的数字，都能在 `details.recalc` 里找到出处
- 近似用的代入值和正文结论能对上（例如「还原项占 0.3%」要真算出 0.3%）
- 全篇不出现两个互相矛盾的参数值
- 图是「数据数组 + 渲染函数」；单条 `points` ≤2400 字符、整份 HTML ≤320KB

## M2. 公理清单（脚本 + 人）

- 第 1 页是 `<ol class="axioms">`，每条 `<li data-axiom="A1">` 带 `[定义]` / `[定律]` / `[经验事实]` **之一**
- 没有 `[教科书结论]` / `[已知结论]` / `[显然]` / `[由…可知]`
- A 节内**没有近似**（「较大时」「忽略…项」「近似」）——近似写在引用它的那一步的「依据」列，并当场给数值
- 每条 A 至少被一条 P 的推导引用一次；没人引用的 A 删掉
- 判据：这条式子在本文档之外还有推导来源吗？有 → 它不能进 A 节（Tafel 方程、Nernst 极限电流都要先证明）

## N. 公理链完整（脚本 + 人）

- 每条 P 的 deriv **首步依据**是 A 编号或「定义」，不是「已知」「题设」「Tafel 方程」
- 之后每步依据只取：A 编号 / 代数 / 量纲 / 近似及条件
- 每条 P 的 deriv 里至少出现一次 A 编号，且 `data-axiom` 指向的编号在 A 节存在
- 全文没有「由式」「由上可知」「显然」「易得」「已知结论」
- 读者只看 A 节 + 这条链，能独立复现整条式子（不能 → 中间少了步）

## O. 孤儿符号为 0（脚本 + 人）

- `calc` 页每个 `<var data-sym="X">` 都能追到某条 P 式的 LHS/RHS，或起点图上的读数（`origin_reads`）
- 每条 P 的 `data-used-in="N"` 指向的 `calc` 页**真的引用**这条式（`data-uses="P3"` 或正文写「P3」）
- 正文引用预备式只写「P2」，不写「式 (P2)」

## P. 页面无元话语（脚本 + 人）

- 标题、lead、正文、列表里没有「开讲前 / 本文档 / 不再假设 / 为了讲清楚 / 本节只 / 后面会 /
  接下来我们 / 不在这几条里 / 先钉死 / 请记住 / 需要说明的是」
- 首页标题只陈述「这页有什么」（例：「三条定义、一条约定、一条定律」），不解释为什么只列这些
- 要留给讲者的话，只能进交付说明或默认折叠的 `<div class="notes">`（打印不展开）

## N 公式手写体、字形覆盖与倾斜

- [ ] 页面里有 `@font-face` 且 `src: url(data:font/woff2;base64,…)`（不是 `local()`、不是外链）
- [ ] `.formula` 命中 `font-family: var(--hand)`；`ol.axioms .eq` 同款
- [ ] 公式区搜不到 `_[A-Za-z]`：下标都排成了 `<sub>`（`data-sym` 属性除外）
- [ ] 手绘笔迹只压 `.expr`，不圈住单位行与推导块
- [ ] 整份 HTML 仍 ≤320KB（手写体子集 ~40KB base64，别超）
- [ ] `var(--hand)` 只出现在 `.formula .expr` / `ol.axioms .eq`；公式里没有中文（子集无 CJK）
- [ ] 公式元素每个字符都在子集 cmap 里（`check_deck.py` 的「手写体」检查）
- [ ] 块级元素不带 rotate/skew；`tools/measure_deck.py --tilt` 表格 |Δy| ≤ 1px
- [ ] `tools/measure_deck.py --fonts` 公式元素只报 DeckHand

## O 展开态（折叠块的空间预算）

- [ ] `python3 tools/shoot_deck.py <html>` 无「展开后溢出」；屏幕态、展开态都量过
- [ ] 复算表单独一页，同页没有图；行数 > 14 已拆 `data-part`
- [ ] `pdfinfo deck-browser.pdf` 页数 == 幻灯片页数；`pdftotext -f N -l N deck-print.pdf`
      能看到该页最后一行（weasyprint 会把溢出内容直接裁掉，页数不涨）

## Q. P 段无定义重述（脚本 + 人）

- 每条 P 的式子归一化后**不等于**任何一条 A 的式子（定义 / 约定 / 纯换算不占 P 号）
- 推导 ≥3 步，且至少 2 步是真实变换（取对数 / 近似 / 相减 / 与 A 对照定系数）
- 判据：删掉这条 P，听众会失去一个可算的中间量；不会 → 降为 A 条目或正文一行
- 预备段允许只有 1 条 P，不为了「看起来完整」凑页

## R. A 节无目标量、无互推、标签正确（脚本 + 人）

- 第 1 页 `data-goal` 声明终点量；A 节任何一条的 LHS 都不许是它
- A 的 RHS 不许以另一条 A 的 LHS 开头（公理之间不互推）
- 标签四选一：`[定义]`（纯定义/纯数学）/ `[约定]`（刻度或参考点的选择）/
  `[定律]`（有独立实验支撑的唯象关系）/ `[经验事实]`（具体体系的测量值，必须带条件）
- `[约定]` 里出现「测量得到 / 实测」→ 复核标签（应改为 `[经验事实]`）
- 每条 A 的 `data-used-in="5,7"` 页真的引用了它

## S. 删页后重排（脚本 + 人）

- 删页后 `data-page` 连续、`N / M` 全部重写、`data-used-in` / `data-uses` 没有指向已删页的编号
- 交付说明里记下删了哪几页、为什么
